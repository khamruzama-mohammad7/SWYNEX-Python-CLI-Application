# Python Task Manager CLI

A simple command-line Task Manager application developed using Python as part of my SWYNEX Technologies Python Developer Internship.

## Project Overview

This application allows users to manage their daily tasks directly from the command line. Users can add, view, complete and delete tasks. Tasks are stored in a JSON file so that data is preserved between program runs.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Persistent storage using JSON
- Input validation
- Exception handling
- Modular Python code

## Technologies Used

- Python 3
- JSON
- Python Functions and Modules
- Exception Handling

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
python main.py
```
